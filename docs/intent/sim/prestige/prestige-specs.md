# Prestige Specs (SIM-MOVE)

## The Move

- [x] **SIM-MOVE-001**: When GreatMeadowMove is applied with at least 71 rostered kittens, the system shall archive every current kitten (Home and Away) into the Family Album as a slim memorial entry (name, trait, rank, profile, and the current generation number) before any reset, never deleting any; with fewer than 71 kittens it rejects with InsufficientResources. (Full skills ride along only in Traveling Baskets, SIM-MOVE-002; the Album is a keepsake, not a full roster copy.)
- [x] **SIM-MOVE-002**: On a Move, the system shall carry up to basket_capacity kittens (Tradition-raised, default 0) into the new meadow, selecting the most-senior (lowest arrived_day) first, keeping their names, traits, ranks, skills, and profiles, and normalizing their meadow-relative fields to the fresh meadow: location Home, arrived_day 0, job_seq/away_seq cleared, job None — except that the Second Wind tradition lets exactly one carried kitten keep its job.
- [x] **SIM-MOVE-003**: On a Move, the system shall carry memory_chest_ratio of each (pre-reset) resource stock into the new meadow, where memory_chest_ratio = the Memory Chest traditions plus 1.5% per Memory Chest structure owned in the old meadow (both read before the reset that clears structures).
- [x] **SIM-MOVE-004**: On a Move, the system shall preserve EXACTLY this legacy set and reset everything else to new-game defaults: preserved — Elder Wisdom, Warm Memories, Passed-Down Wisdom, serenity, enlightenment tier, purchased Traditions (and derived nine_lives_ratio), the Family Album, the achievement record (SIM-ACH), the Adventures state (reward pool, completions, and the armed→active transition), the cosmic/dreamtime legacies (sites_reached, dream_looms, the distant_dawn flag, and the reverie stock — permanent dreamtime knowledge and currency), the game-speed setting, the RNG (continues, never reseeded), and generation (incremented); reset to defaults — structures, ideas, refinements, house rules, resources (before the Memory Chest is placed), the kitten roster (before Traveling Baskets are placed), devotion, peak_devotion, rite_counts, rites, dream_drift, Rainbow Arches and the whole mystic chain, Promises, colony discovery/Pen Pals, the Elder appointment, mess, pity/famine/recovery clocks, next_seq, zoomies, kites_high_water, pending sky event, jamboree, the Star Whale visit, stirred-dreams heat, and the tick counter; the reveal worklists are rebuilt from the emptied `revealed` set (as on load).
- [x] **SIM-MOVE-005**: A Move shall never decrease any legacy currency and never remove an entry from the Family Album. (Spending Elder Wisdom on Traditions and converting it via Pass It Down are player-chosen acts outside a Move — the cozy "pass the torch", not a Move-inflicted loss.)

## The Legacies

- [x] **SIM-MOVE-006**: On a Move, the system shall add max(0, kittens − 70) to Elder Wisdom, plus one per game-millennium elapsed since the last Move.
- [x] **SIM-MOVE-007**: The system shall contribute Elder Wisdom to production stack layer 7 as +1% per point, limited_dr-capped at (2.0 × nine_lives_ratio), and to storage as +0.1% per point (linear); the cap and slope scale with the Nine Lives traditions.
- [x] **SIM-MOVE-008**: On a Move, the system shall add karma_gain(kittens) = (k−35) + 3·max(0,k−60) + 4·max(0,k−100) + 5·max(0,k−150) + 10·max(0,k−300) + 15·max(0,k−750) to Warm Memories (accumulated across Moves), and expose warm_memory = unlimited_dr(Warm Memories, 5) as +1% happiness per point.
- [x] **SIM-MOVE-009**: When PassItDown is applied, the system shall convert all Elder Wisdom into Passed-Down Wisdom (one-way), which contributes a second production pool of +1% per point capped at +100% (raised to +400% once the dreamtime leaf's distant_dawn flag is set) and storage of +0.05% per point.

## Traditions

- [x] **SIM-MOVE-010**: The system shall define exactly the traditions of the prestige design's shop table — Elder-Wisdom costs and effects — buyable once each via BuyTradition (permanent across Moves; InsufficientResources when unaffordable), their effects flowing through the effect-key system.
- [x] **SIM-MOVE-011**: The Nine Lives traditions shall each add 0.05 to nine_lives_ratio (default 1.0), raising both the slope and the +200% cap of Elder Wisdom's production contribution.
- [x] **SIM-MOVE-013**: The system shall apply structure-price-reduction traditions through a GlobalPriceRatioDelta effect consumed by next_cost() (and the reveal-cost path): cost = base × ratio^owned × (1 − limited_dr(price_delta, 0.5)), so stacked reductions are DR-clamped and a price multiplier can never reach zero.
- [x] **SIM-MOVE-012**: The system shall apply Tradition effects (price reductions, basket capacity, memory-chest ratio, arrival speed, and the rest) through the typed effect-key system, and no Tradition shall ever be un-bought or disabled.
- [x] **SIM-MOVE-013**: Where the Prism Sight tradition is held, the system shall multiply each day's prism-descent chance and rainbow-shower chance by 1.1.
- [x] **SIM-MOVE-014**: The system shall give every Tradition a blurb — a short joke, then the tradition's effect in plain words — marking each resource it names as SIM-CUR-014 marks them.
