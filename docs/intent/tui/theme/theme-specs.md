# Theme Specs (TUI-THEME)

## The Ground

- [x] **TUI-THEME-001**: The system shall paint no background of its own, rendering ordinary text in the terminal's inherited foreground so the game is legible in a light terminal and a dark one without detecting which it is in.
- [x] **TUI-THEME-002**: The system shall keep every palette value — the five state colours, the seven ring hues, and every colour a blended coat puts on a character — within a mid-luminance band, at a WCAG contrast ratio of at least 3:1 against pure black and at least 3:1 against pure white, so every value reads on a dark ground and on a light one.

## What Colour Means

- [x] **TUI-THEME-003**: The system shall use colour for two things only — state, worn by marks (glyphs, tags, chips, and whole lines), and identity, worn by a resource's name as its coat — so that a structure, idea, job, kitten, or any other named thing takes its colour from its current state and never from which item it is, and a resource's coat never varies with the resource's stock, cap, rate, or any other state.
- [x] **TUI-THEME-004**: The system shall define exactly six palette roles — dim, ready, partial, attention, milestone, and the inherited foreground — and a ring of exactly seven coat hues, and shall render no colour outside the five state colours, the seven hues, the colours on a blended coat's path between its stops, and the seasonal chrome accent.
- [x] **TUI-THEME-005**: The system shall render mood with no colour at all, the mood word being its only channel.
- [x] **TUI-THEME-006**: The system shall convey focus through the cursor glyph and, where more emphasis is needed, reverse video — never through a palette colour.
- [x] **TUI-THEME-007**: The system shall render reverse-video emphasis by inverting the terminal's own foreground and background pair rather than a palette colour, so emphasis works in either polarity.

## The Seasonal Accent

- [x] **TUI-THEME-008**: The system shall draw the inert chrome — the header rule and every pane divider (TUI-RENDER-016), and nothing else — in the accent of the season held by the snapshot the frame draws, changing on the same frame as the header's season word with no blend across the turn, and on the header rule colouring the underline alone so every character above it keeps its own colour, so the pane's chrome tracks the year.
- [x] **TUI-THEME-009**: The system shall apply the seasonal accent to no element that carries state and to no coat, so no colour is ever ambiguous between a state and a season and no store changes its look with the year.

## Colour as the Second Channel

- [x] **TUI-THEME-010**: The system shall pair every meaning colour carries with a glyph, a word, or a fill that carries the same meaning, so that rendering with all colour removed loses no information the player needs.
- [x] **TUI-THEME-011**: The system shall give each of the three states whose colours are nearest in hue — affordable, partially affordable, and attention — a non-colour channel neither of the other two uses: affordable the marker `●`, partially affordable the marker `◐`, and attention each chip's own glyph (TUI-NAV-020), a word — the `full` tag — or an armed row's expansion beneath itself (TUI-NAV-077), never `●` or `◐`; and, among `ready`, `partial`, and `attention`, shall draw each of those glyphs only in its own state's colour — `●` never in `partial` or `attention`, `◐` never in `ready` or `attention`, a chip's glyph never in `ready` or `partial` — an armed row wearing `attention` on its expansion and nowhere on its own line, whose marker keeps its availability colour; both whatever values the palette holds, so a red-green deficiency that compresses those hues never collapses two states into one appearance.

## Terminal Capability

- [x] **TUI-THEME-012**: When the terminal does not advertise truecolor support, the system shall say so once at startup in plain words naming what to set, and shall then render unchanged rather than substituting a reduced palette.
- [x] **TUI-THEME-013**: The system shall emit the truecolor notice before entering the alternate screen, alongside the other startup messages, so it is still on the player's scrollback after the game exits rather than being erased with the alternate screen.
- [x] **TUI-THEME-014**: The system shall render an owned or completed one-shot in dim, so a finished row recedes rather than competing with the rows that can still be acted on.
- [x] **TUI-THEME-015**: The system shall draw every element that wants notice in the one `attention` value, and nothing else in it — each attention chip whole, its glyph, any count, and its word, at every width step the header takes and the `★N new` chip included, but not the blank columns between chips or the header's facts; the `full` tag on a capped store, but not the store's name, figures, fill bar, or rate; and an armed row's expansion wherever it is drawn, but not the row's own line or the hint bar — so the role means "this wants you" wherever it appears, is never subdivided per surface, and is lent to nothing that does not want notice, a footer note being drawn in the inherited foreground.

## Coats

- [x] **TUI-THEME-016**: The system shall give every resource a coat — stops, each one of the ring's seven hues, exactly one for a solid coat and two to four for a patched or blended coat with no two consecutive stops the same hue, together with its dressing — fixed for the life of the game, with no two resources sharing a coat, a coat being its stops in order together with its dressing, and with each of the three dressings worn by at least one resource.
- [x] **TUI-THEME-017**: The system shall lay a coat across the characters of a resource's name — each character one Unicode scalar value, a space counting as a character under every dressing — by its dressing: a solid coat's one stop on every character; a patched coat's stops as consecutive runs in the coat's order, one run per stop, every run as long as the quotient of characters by stops and the first runs, as many as the remainder, one character longer, a name with fewer characters than stops wearing the first as many stops as it has characters; and a blended coat's colour at each character's position, the positions evenly spaced from the first character at the first stop to the last character at the last, along the piecewise-linear path through its stops in OKLab with each segment between consecutive stops an equal share of the span, a one-character name wearing its first stop.
- [x] **TUI-THEME-018**: The system shall keep every colour a coat can put on a character — each stop, and the colour at every position along a blended coat's path that a name of up to thirty-two characters can put a character at — at a CIE76 colour difference of at least 18 from each of the five state colours, `dim` included, so that a blended coat is allowed only between stops whose path keeps that clearance.
- [x] **TUI-THEME-019**: The system shall draw a resource's name in its coat where the name stands as a field — the store's name in the sidebar, the name on its stores row, the name of each component in a list row's cost field and in an open count prompt's preview wherever that preview is drawn, and in the inspector the name line of a stores row and the name heading each cost line, unit-price line, and preview component, the inspector's cost lines being drawn in the inherited foreground whatever a component's shortfall — and nowhere else, and so in no sentence, the name wearing the line's own colour in the header, the ticker, the report banner, the Journal, the away report, a footer note, the hint bar, an armed row's consequence summary, the inspector's statement of what an item does, and the find palette's result lines.
- [x] **TUI-THEME-020**: The system shall wear a coat only on a line drawn in the inherited foreground, in `ready`, or in `partial`, and never on a line drawn in `dim`, `attention`, or `milestone` nor on a reversed line, where the name wears the line's colour; and on a line that carries a coat, only the name's characters shall wear it, the figures, separators, blank columns, and every glyph wearing the line's own colour, so that no marker glyph ever wears a coat.
- [x] **TUI-THEME-021**: When a coated name is shortened with an ellipsis (TUI-RENDER-014), the system shall keep on each character drawn the colour it has in the whole name and shall draw the ellipsis, one cell, in the colour of the character at its position in the whole name, so a store's leading characters wear the same colours at every width.
