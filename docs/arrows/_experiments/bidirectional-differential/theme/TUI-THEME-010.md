# TUI-THEME-010 — colour is never the only carrier of meaning

**Classification:** `B-ONLY-DRIFT`
**Runs:** A=3, B=3

## What the blind readers saw

All three readers described the six-role palette, which is a different spec entirely. The requirement is about every place colour is used — that a glyph, a word or a fill carries the same meaning — and it was cited on the role definition, which is the one place the question does not arise.

## Repair

No repair available in kind: the requirement has no entry point, being a property of every call site. Left cited where it is, and recorded as the same shape as TUI-THEME-015.
