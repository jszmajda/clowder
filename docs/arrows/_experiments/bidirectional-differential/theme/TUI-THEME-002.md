# TUI-THEME-002 — the palette sits in a mid-luminance band

**Classification:** `B-ONLY-DRIFT`
**Runs:** A=3, B=3

## What the blind readers saw

All three B-runs recovered the role-to-value mapping and read the values back exactly. None recovered that the values sit within a luminance band clearing contrast against both a near-black and a near-white ground — a constraint on the numbers rather than on the code that serves them. A reader given a table cannot see which of its properties were chosen and which merely happened.

## Repair

No repair. This is the content-table class: the constraint is checkable and is checked, but only a test can express it.
